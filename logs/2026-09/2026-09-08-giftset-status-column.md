### 판정 수치화 — `core.prescribe()` (사용자 요구: "AI 판단이 아닌 숫자적 판단")
기호 `S=세트재고(0클램프) · v=일평균세트7 · R=잔여시즌일 · D=S/v`.

| 판정 | 권장 수치 | 근거식 |
|---|---|---|
| 🔴 인하 집행 | 마진 −Δ%p (가격 −x%) | `Δ = min(마진여력, 이월비용률) × min(k−1, 1)`, `k = (S/R)/v` |
| 🔵 인상 검토 | 마진 +Δ%p (가격 +x%) | `Δ = (계획마진 − 현재마진) × 0.5 × 여유율`, 여유율 `= 1 − D/R` |
| 🟡 추가매입 | +N세트 (B박스) | `N = v×R − S`, `B = ceil(N/박스내품)`, 매입액 `= N × 세트원가` |
| 🟢 유지 | 이월 예상 / 촉진 인하 −Δ%p | 마감후잔여세트 표기. **촉진 대상이면 인하 여력을 계산** |

- **상한의 근거**: 인하 상한 = **이월비용률 3.3%p**(§7 — 그보다 크게 깎아 지금 터는 건 이월보다
  손해) · 하한 = **절대하한 3%** · 인상 앵커 = **계획마진 8.8%**, 절반스텝은 두뇌④(ADR 0026) 관례.
- 가격 환산은 원가 고정 가정 `p=C/(1−m)` → `Δp/p = (1−m)/(1−m′) − 1`.
- **상태 반영**: `판매중지`→가격 조정 대상 아님 · `추가입고없음`+🟡→"추가매입 불가, 잔여 소진" ·

  `촉진 인하 −3.3%p (가격 −3.4%) · 마감 후 1,356세트(3,580만) 남음` 으로 산출된다.

## 후속 ④ — 인터넷사업부 export = 분류 사전 (커밋 `515e3447`)

후속 ③에서 드러난 "미분류 5.55억" 의 근본 해법. 사용자가 **인터넷사업부 매출만 뽑을 수 있다**고
해서, 그 파일을 **매출이 아니라 소속 판정의 오라클**로 쓰는 경로를 만들었다.

- 파케이는 전사 유지(대시보드·재고지능 공용) → 사업부 export 는 **적재하지 않는다.**
- `_division_from_export()` — export 내 미매칭 상호명 → 온라인B2B / 같은 기간 파케이에만 있는
  상호명 → 사업부밖. 이미 분류된 건 후보에서 자동 제외.
- 데이터 적재 탭을 **①전사 적재 / ②분류 사전** 두 섹션으로 분리. 기존 🚫 가드 문구도 ②를 가리키게 수정.
- 전사 export 오업로드 감지 = 거래처 수가 같은 기간 파케이의 95% 이상이면 경고.

**검증(합성 골든)** — 사업부 8곳 중 오프라인 2곳을 뺀 export 를 넣어:
b2b 후보 = {태성전기, 빅세일컴퍼니}(표기규칙에 잡히는 지마켓·나들·자사몰, 제외계정 로켓창고는 자동 배제) ·
out 후보 = {푸드앤플러스, 삼일유통} · 일부를 화이트리스트에 넣고 재실행하면 그것만 후보에서 빠짐 ·
전사 export 를 넣으면 오프라인까지 b2b 후보가 되고 경고 조건(export≥파케이×0.95)이 성립. 전건 PASS.

**다음** — 사용자가 사업부 export 를 ②에 올리면 미분류가 0 이 되고, 그때의 `마진율`·`YoY`·`판정`이
사업부 스코프 기준으로 정확해진다. 그 값으로 D-15(9/10) 판정을 봐야 한다.
