# 2026-09-02 — 한진 개별발송 7·8차 (다온푸드서비스 4장 · 한국건설자재 21장)

## 무엇
같은 날 4·5·6차에 이어 2건 추가.
- **7차** 다온푸드서비스 → 구내식당 3처, 스팸8호 10세트 = **송장 4장** (발행·정제 완료)
- **8차** 한국건설자재 → 17처, G호 63세트 = **송장 21장** (접수 양식 배포, 업로드 대기)

## 7차 — 다온푸드서비스 (이미지 입력)
- 입력이 **표 이미지 1장 + 보내는이 한 줄**. 상품 `스팸8호`(45-21, 박스내품 5).
- ★ **수량 단위 되묻기** — 표의 `2 / 1 / 7`이 세트인지 박스인지 불명. 세트면 송장 4장, 박스면 10장으로
  2.5배 차이라 §2 규칙대로 확인 → **세트** 확정.
- 분할: 설정화 2세트→1행 · 박준아 1세트→1행 · 이한별 **7세트→2행(5+2)**.
- 보내는분 = 성명·전화만 거래처(`주식회사 다온푸드서비스` / `010-8797-8727`), 주소·우편번호는 판교대리점 고정값
  (6차 태성전기와 같은 대행 발송 형태).
- 배송메세지1 `9월 2~3주차 배송 희망` 전 4행.
- 회수 `463192855930~963` 4장. 검증 2종 통과(세트합 10 · 초과행 0 · 중복 0 · AC 전건 1).

### ★★ 우편번호 공란 통과 — 2회차 실증
- 부산 서면로 74(아이온시티) / 대구 명륜로23길 106(반월당클래시아2차) / 부산 화명대로 1(베스티안부산병원)
  3곳 모두 **5자리 우편번호를 못 찾아 공란으로 접수**. 추정 기입은 §4 금지라 하지 않음.
- 결과 **전건 발행 + 한진이 우편번호 자동 부여**: 47286 / 41958 / 46524.
- 6차(태성전기 68행 전건 공란 → 65건 발행)에 이어 **두 번째 확증**.
  → §8 함정의 "우편번호는 보조 수단, 추정치 넣느니 비운다"가 규칙으로 굳어짐.
- 의심했던 `명륜로23길 106`(번지가 길 이름 대비 큼)도 정상 통과 — 오타 아니었음.

## 8차 — 한국건설자재 (설26 파일 재사용)
- 입력 `2026년_추석_선물리스트__햄세트__본사외_.xlsx` — 시트 `26년구정선물_본사`(리스트)·`주문서`·`송장`.
  뒤 두 시트는 **설26 실적**이 남아 있는 재사용 파일.
- ★ **품목 특정 되묻기** — 리스트엔 "햄세트"·박스단가 85,000만 있고,
  **박스내품 3 + 박스매입 73,500이 45-07(G호)·45-07-06(J호) 둘**이라 단가로 특정 불가 → 되물어 **G호** 확정.
- ★ **매출자료로 과거 건 실증** — 시트명 `26년구정`만으로 짐작하지 말고 대사:
  한국건설자재 거래 이력 = 2025-09-19 45-07 72세트 / 2025-09-30 −3세트 반품 /
  **2026-02-03 45-07 69세트 + 택배비 23건** → `송장` 시트 23장·69세트와 정확히 일치, 설26 확정.
  덤: 추석25 72세트(24박스) → 추석26 63세트(21박스) = **−12.5%**. 세트당 단가는 설26과 동일한 28,333.
- 21행 생성. **BOX 2인 4곳**(대용건설·서원토건·성호에스씨·오주건설)은 각 2행.
- 정합 검증: BOX합 21 = 시트 합계행 21 / 수량합 63 = 시트 63 / **행별 `수량 = BOX × 3` 개별 검증**
  (합계만 맞고 행별로 어긋나는 경우 차단).
- 보내는분 `㈜한국건설자재 온진수대표` / **010-8923-6644**(설26의 010-3125-9800에서 사용자 지시로 변경) /
  경기도 화성시 송산면 삼존서길 168. 우편번호는 설26 주문서도 공란이라 동일.
- 받는분성명: 리스트 `구분` 열이 **현장**인 3건은 담당자명만 적혀 있어 설26 주문서 관행대로
  **업체+담당자**(`신한 김성권부장`·`로아건설 안성준부장`·`아이엘 김지호과장`)로 보정.
- 배송메시지 없음(사용자 지시).
