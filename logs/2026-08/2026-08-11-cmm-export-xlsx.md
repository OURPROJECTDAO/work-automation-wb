# 2026-08-11 — 채널마진모니터 표 내보내기 CSV → XLSX

## 무엇 / 왜
표 내보내기 버튼이 CSV(utf-8-sig)였다. 사용자 요청 = xlsx로 교체. CSV는 엑셀에서 열 때마다
**관리코드가 날짜로 변환**(`45-21`)되고 **알리 상품번호 16자리가 지수표기**로 깨지는 문제가 있어,
xlsx로 바꾸면서 코드류를 텍스트 셀로 박제했다.

## 변경 (page-only · 커밋 8491a6a0)
`app/pages/6_채널마진모니터.py`
- 신규 헬퍼 `_export_xlsx(frame, title)` (openpyxl 직접 작성):
  - **텍스트 강제**(`_X_TEXT`): 상품번호·관리코드·상품명·규격·코드유형·탐지·권장가/제한·비고
    → 날짜/지수 자동변환 차단(전역 pitfalls '코드 열은 문자열 유지').
  - **숫자 `#,##0`**: N·재고·매입가·판매가·배송비·정산액·전월매출·전월매출(전체).
  - **퍼센트 `0.0%`**: 마진율·기준마진율(값은 소수 그대로 → 엑셀에서 정렬·필터 가능).
  - 빈값은 **빈칸 유지**(0으로 채우지 않음) · 헤더 볼드+음영 · `freeze_panes A2` · auto_filter · 컬럼 폭.
- 버튼 교체: `📄 XLSX 다운로드 (…건)` · 파일명 `{채널}_마진모니터_YYYYMMDD.xlsx` · 미사용 `StringIO` import 제거.
- 대상 범위는 종전과 동일 — **선택분 있으면 선택, 없으면 현재 필터 전체**.

## 검증
실데이터(알리 312건) 생성 → 313행/18열 · freeze `A2` · filter `A1:R313`.
셀 타입 확인: 상품번호 `'1005007008720764'`(str, 지수표기 없음) · 관리코드 `'31-22-02-CB-31-03-05'`(str) ·
매입가 int + `#,##0` · 마진율 0.0941 + `0.0%`. `ast.parse` 통과.
