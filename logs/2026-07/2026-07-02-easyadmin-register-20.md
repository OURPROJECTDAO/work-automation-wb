# 2026-07-02 — 이지어드민 상품등록 20건 (sikbom 3차와 동일 소스)

## 무엇
- sikbom-register 3차 배치(20건)와 동일한 신규상품을 이지어드민(정산 필수 경유 채널)에도 등록.

## 왜
- easyadmin-register.md: "신규 상품은 모든 판매채널 외에 이지어드민에도 등록해야 함" — 필수 병행 작업.

## 변경
- 사용자가 실제 업로드 양식(`상품_일괄등록_샘플_v10.xls`, 69열 헤더 1행짜리 구.xls)과 실등록 예시
  (`이지어드민상품목록.xlsx`, export 포맷 66열)를 제공 → 문서화된 §기입 7열 규칙을 실물로 재검증.
- 재검증 결과 기존 문서 규칙과 100% 일치 확인, 구분자 디테일 확정: A(상품명)는 `[코드]` 뒤 붙여쓰기(공백없음),
  D(공급처옵션·박스전용)는 `[관리코드]-이름 [규격]`처럼 하이픈+공백 패턴.
- 20건 생성: 낱개17(PC코드+ㅁ구분자 레거시 포맷)·박스3(관리코드 직결 포맷). AC(합포가능수량) = 낱개는 박스내품,
  박스는 원본 파일의 합포값 그대로(2·3 같은 비1 값도 정확히 반영: 비락수정과=1·펩시2종=2/3 등).
- 산출 `이지어드민상품등록_20건.xlsx`.

## 검증
- xlrd로 읽은 원본 헤더(69열) 그대로 사용, 기입 7열(A/B/C/D/E/AB/AC) 위치가 doc과 일치.
- 실등록 예시 8건(낱개3·박스5)과 대조해 포맷 100% 일치 확인 후 생성.
