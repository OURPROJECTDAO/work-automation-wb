# 제이티유통(JT) B2B 공급단가 운영

㈜제이티유통에 낱개·소분·선물세트를 공급하는 B2B 건. 단가표는 `work-automation-app/reference/sku_list.csv`(122행)가 정본.

## 1. 단가 구조 — ★ 이것부터 읽을 것

**발주서 판매가 = 공급가(VAT 포함) × 수량 + 배송비 3,000**

2026-08-24 발주서 전건에서 오차 0원으로 검증됨:
- 스팸6호 4세트 `34,400×4 + 3,000 = 140,600` ✓ / 2세트 `71,800` ✓ / 1세트 `37,400` ✓
- 스팸8호 3세트 `23,300×3 + 3,000 = 72,900` ✓ / 1세트 `26,300` ✓
- 스팸12호 5세트 `21,400×5 + 3,000 = 110,000` ✓ / 3세트 `67,200` ✓
- 스팸복합1호 1세트 `21,100 + 3,000 = 24,100` ✓ / 튜나리챔77호 1세트 `35,100` ✓

→ ERP 매출자료의 `판매단가`가 단가표 공급가보다 높게 보이는 것은 **배송비가 얹혀서**다. 단가표 이상이 아니다.

## 2. ★★ VAT 기준 — 매입·판매 **둘 다 VAT 포함**

`purchases/buyin_*.parquet` 에서 검증(단가 ÷ (공급가액÷수량) = 정확히 1.1000):
| 관리코드 | 단가 | 공급가액÷수량 | 비율 |
|---|---|---|---|
| 45-05 | 35,000 | 31,818.19 | 1.1000 |
| 45-21 | 23,500 | 21,363.64 | 1.1000 |
| 23-18 | 800 | 727.27 | 1.1000 |

**따라서 마진 = (공급가 − 원가) ÷ 공급가 로 그대로 계산한다.**
한쪽에서만 VAT를 빼면 전 품목이 −10%p 밀려 "전부 역마진"이라는 거짓 결론이 나온다(2026-08-25 실사고, §6).

## 3. 원가 산정
- **선물세트**: 세트원가 = `박스매입단가 ÷ 박스내품` (product_master)
- **일반·소분**: `매입단가 × sku_list 내품수량`
- 관리코드가 `원코드` 컬럼에 별도로 있으면 그쪽으로 product_master 조회(소분 코드는 `XXX1EA-원코드` 형태).
- ⚠️ `product_master` 매입단가는 **이동평균**이라 최신 매입가와 벌어진다.
  예: 23-18 하늘보리 — 2026-07-02 박스 12,500 / 07-03·07-31 박스 16,000 매입인데 기준값은 11,233.
  거래처 제시 단가를 산정할 땐 최신 매입가 확인이 필요.
- ⚠️ ERP 매출자료 `단위원가`도 이동평균이라 product_master와 다를 수 있다(51-30-01: ERP 29,400 ↔ pm 31,500).

## 4. 목표 마진
**8% = 선물세트 기준마진 6% + 안전마진 2%** (사용자 확정 2026-08-25).
B2B라 실제 채널 수수료는 없으나 완충으로 2%p를 얹는다. 하한선은 7%(5+2).
`권장 공급가 = ceil100(원가 ÷ (1 − 목표마진))` — 양쪽 VAT 포함이므로 1.1 곱하지 않는다.

## 5. 배송비
건당 3,000원(VAT 포함 → net 2,727) 대 실배송 원가 3,000원 → **건당 −273원**.
2026-08 기준 287건 = −78,351원. 본전을 맞추려면 3,300원. 상품 단가와 별개 협상 항목.
`00-12 C타입 택배비-3000` 전표는 판매단가 0으로 원가만 계상된다(배송비 수입은 상품 판매금액에 포함돼 있음).

## 6. ★ 함정 — 소분 품목의 ERP 수량 오적용
**2026-08-24 45-10-10(CJ 스팸12호)**: 발주서는 8세트(5+3)인데 ERP 수량이 **40**(=8×박스내품 5)으로 들어갔다.
판매금액 177,200은 정확한데 수량만 5배 → 원가가 800,000으로 부풀어 **−698,400** 손실로 표시.
같은 날 스팸6호(8)·스팸8호(7)는 정상이었다. → **품목별 매핑 문제**이며 온라인 미등록 품목에서 발생.
**대응**: 제이티 실적에 큰 역마진이 보이면 먼저 `발주서 세트수 ↔ ERP 수량`을 대조한다. 단가 문제로 넘겨짚지 말 것.
(2026-08-25 전표 수량 8로 정정 완료)
