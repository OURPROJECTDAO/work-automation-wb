# workflows/giftset-season-ops.md — 선물세트 시즌 운영 (추석/설)

> **성격**: 챗 네이티브 · 앱 미탑재 · **시즌 한정 트랙**(명절 D-31 개시 ~ D+15 정산 후 닫음).
> 선물세트는 두뇌④ 시즌 제외 축(⑧)이라 채널마진모니터·두뇌④ 자동 감시가 **안 붙는다**.
> 그래서 시즌 동안만 사람+AI 캐치업으로 대체 감시하는 트랙. 시즌 끝나면 같이 닫는다.
> 정본 스코프 = **오픈마켓(나들·오프라인 제외)**. 나들/오프라인은 이 트랙 밖(별도 관리).

## 0. 한눈에 로직

```
[준비 D-31까지]  등재갭 해소 + 분류 등록 + 매입 인상 전가 + 기준선 박제
        ↓
[관측 D-30~20]  주2회 — 진도 밴드 대비 초기 반응만 확인 (이 구간 매출 15%)
        ↓
[승부 D-19~10]  매일 — 인하 재원 집행. 여기서 88% 결정
        ↓
[마감 D-9~3]   격일 — 인하 vs 이월 판단 (손익분기 3%p)
        ↓
[정산 D+1~15]  2회 — 실적 확정 · 이월 재고 · KB 기록 · 트랙 닫기
```

## 1. 목표 체계 — 마진을 "예산"으로 전환

볼륨 우선(회사 방침) 상황에서 마진을 *지키는 것*으로 두면 목표 미달을 감수하게 되고,
반대로 무제한 인하하면 바닥을 뚫는다. → **인하 재원(budget)** 개념으로 전환한다.

| 항목 | 2026 추석 값 | 성격 |
|---|---|---|
| 매출 목표 | **15.0억** | 커밋(양보 불가) |
| 이익 하한 | **1.10억** | 추석25 0.91억 +21% |
| 마진 하한(포트폴리오) | **7.3%** | = 이익하한 ÷ 매출목표 |
| 계획 마진 | **8.8%** | 채널별 목표 가중 |
| **인하 재원** | **2,200만원** | = 매출목표 × (계획마진 − 마진하한) |
| 개별 상품 절대하한 | **3.0%** | 두뇌④ `MIN_SELL_MARGIN`과 동일. 예외 없음 |

- 가격 인하 = **재원의 집행**. 매 세션 **잔액**을 추적한다. "얼마 깎았나"가 아니라 "얼마 남겼나".
- **재원 소진율 > 진도율**이면 경고. (예: D-15에 진도 43%인데 재원 60% 소진 → 그 페이스면 하한 관통)
- 인상으로 회수한 마진은 재원에 **적립**한다(순액 관리).

### ★ ESM 목표의 실제 기저 = **지마켓 단독** (2026-08-12 확정)

**옥션 거래 종료**(사용자 확정). 실적상 이미 반영돼 있었다 — EasyAdmin 주문 기준 ESM 내 옥션 비중:
추석24 **54.2%** → 추석25 **28.9%** → 설26 **0.5%**. 옥션 판매중지일이 2025-11-14(추석25 종료 직후)에
몰려 있는 것과 일치. cmm ESM 파싱이 `include_row_if_col_value F=='지마켓'`인 것은 원래 다운로드
중복제거 목적이었으나, **이제 거래 정책과 일치**한다(의미가 달라짐 — 지마켓만이 곧 우리 판로).

→ 추석25 ESM 5.37억 중 **지마켓 단독은 약 3.82억**(71.1%).
→ **ESM 목표 6.0억 = 지마켓 단독 +57%.** (앞서 "+12%"로 본 것은 옥션 포함 기저와 비교한 오류)

**사용자 결정(2026-08-12) = ③ 현행 유지**(ESM 6.0억 유지, 총액 15억 유지).
대안이던 ①(ESM 4.6억으로 낮추고 차액을 쿠팡·스스 재배분)·②(총액도 13.6억으로 하향)는 기각.

**달성 경로 = 가격이 아니라 품목 수.** ESM은 폭으로 푸는 채널이 됐다.

| 지마켓 판매코드 | 코드당 필요 | 작년 대비 깊이 |
|---|---|---|
| 29개(작년 수준) | 2,100만 | +57% |
| 35개 | 1,700만 | +30% |
| **41개(전 라인업)** | **1,500만** | **+11%** |

현재 ESM 등재 19/41 → **22종 추가 등재가 곧 목표 달성 수단**(G호 승계 J호·신규 7종 포함).
29개로 버티면 +57%를 가격으로 만들어야 해 마진 9.0% 목표와 양립 불가.

**리스크 완화**: 옥션 단독 판매코드는 **2개뿐**(나머지는 지마켓에도 등재돼 있던 것)이라 상품이 통째로
사라지는 구조가 아니다. 설26에 옥션이 0.5%로 빠졌는데도 지마켓 단독은 설25 대비 크게 성장했다.

**체크포인트(하향 트리거)**
- D-20(9/5): ESM 누적 < 0.9억(목표의 15%) → 경고
- **D-15(9/10): ESM 누적 < 3.0억(밴드 하단 2.6억) → ESM 목표 4.6억으로 하향 + 차액을 쿠팡·스스로 재배분**
  (D-10 넘어가면 재배분할 시간이 없다)

⚠️ 미확인 = 옥션 종료가 **선물세트만인지 전 품목인지**. 전 품목이면 cmm ESM 기준마진·가격변경 로직과
대시보드 ESM 채널 실적도 지마켓 단독 기준으로 재점검 필요.

★ **캐시노트·알리는 인하 대상에서 제외.** 규모가 작고 마진이 높아 여기를 지켜야 저마진 채널

## 6. 판단 규칙 (4분면) — 두뇌④ 4분면과 동형

| | **재고 과잉**(소진예측 > 잔여일) | **재고 부족**(소진예측 < 잔여일) |
|---|---|---|
| **진도 미달** | 🔴 **인하 집행** — 재원 차감 | 🟡 **추가 매입 검토** — CJ/동원 시즌 생산 여부 확인 |
| **진도 초과** | 🟢 유지 | 🔵 **인상 검토** — 재원 적립 |

**인하 집행**
- 1회 **−2~3%p**, **최소 3일 관측** 후 재판단. (잔여 5일 이하면 관측 없이 즉시)
- 단위 = **채널 × 상품**. 같은 세트도 ESM 미달 / 스스 정상일 수 있다.
- 3%p 절대하한 클램프 — 권장 < 3%면 3%까지만 내리고 그 밑은 막는다.
- 캐시노트·알리 제외.

**인상**
- 품절 임박(소진예측 < 잔여일)인데 진도 초과면 **올린다**. 어차피 팔릴 물건을 싸게 주는 건 재원 낭비.
- 회수분은 재원에 적립 → 다른 상품 인하 여력이 된다.

## 7. 마감 국면 전용 — 인하 vs 이월 손익분기

선물세트 잔여 재고는 **죽는 게 아니라 다음 설로 이월**된다.
★ 근거: 구성 변경은 **추석 직전에만** 발생(2024추석 구성→설25 유지 / 2025추석 구성→설26 유지).
   즉 추석 물량의 다음 설 이월은 이 상품군의 **정상 운영**. (logs/2026-07-29-giftset-season-analysis)

- **이월 비용 ≈ 3.3%** = 자금비용(연 5% × 8개월 ≈ 3.3%) + 재고 위험
- → **3%p 넘게 깎아서 지금 터는 것은 이월보다 손해**

| 상황 | 판단 |
|---|---|
| 인하폭 3%p 이내로 소진 가능 | **인하** |
| 3%p 초과 필요 | **이월** |
| 이미 이월 재고 누적 큰 품목(45-21 스팸8호·50-32 리챔G9) | 누적 부담 고려해 **인하 쪽으로 기울임** |

## 8-B. ★ 선물세트 등록 예외 규칙 (일반 상품과 다름 — 2026-08-13 확립)

| `sub_list` 구분 | `낱개1개` | **`선물세트`** |
| `unit_list` 원코드 / 구분 | 원 박스 코드 / `낱개` | **자기 자신 / `선물세트`** |
| `unit_list` 입력값 | — | **1 ÷ 박스내품** (3세트=0.3333·5세트=0.2) |
| `sobun.csv` | 소분코드 등록 | **등록 안 함**(선물세트 0건) |
| `product_attributes` | — | 식품음료=`선물세트` · **합포수량=1**(전건) · 최종분류=`선물세트` |
| `logistics_classification` | 식품/음료 | `선물세트` |

→ 소분 개념이 없다. 자기참조라 `sobun`에 안 올라가고 변환도 없다.

### (2) 천년경영 ERP 업로드 — **항상 낱개 시트, 수량·단가 그대로 통과**
`sub_list` 멤버십이 전체↔낱개 분기의 유일 근거인데 선물세트는 전건 등록돼 있으므로 **낱개 시트로 이동**.
거기서 `J(기입수량)=D×낱개개수=D×1=D`, `K(낱개단가)=H×D/J=H` → **수량도 단가도 무변환 통과**.
즉 **1세트 단위로 팔고 1세트 단위로 ERP에 꽂힌다.**
`unit_list` 입력값(1/박스내품)은 박스 발주를 세트로 환산할 때 쓰는 값으로 ERP 업로드 경로와 별개.

### (3) 채널 등록 — 1세트 + 박스 **동시 등록**, 판매자상품코드는 둘 다 관리코드
| | 일반 상품 | **선물세트** |
|---|---|---|
| 판매자상품코드 | 박스=관리코드 / 낱개=PC코드 | **둘 다 관리코드**(PC 없음) |
| 등록 단위 | 박스 or 낱개 택1 | **1세트 + {박스내품}세트 동시** |
| 상품명 끝 | `{박스내품}개` | **`1세트` / `{박스내품}세트`** |
| 합포 N(배송) | 합포장 × 박스내품 | **합포수량 1**(attributes 전건 1) |
| 판매가 기준 매입가 | 박스=박스매입단가 | **1세트=매입단가 · 박스=박스매입단가** |

### (4) ★★ hapo_multiplier — **박스가 아니라 "1세트"에 N을 넣는다**
`resolve_code`는 **관리코드 → `박스매입단가`**를 base로 잡고 `매입가 = base × N`.
선물세트는 두 리스팅이 같은 관리코드를 쓰므로:

| 리스팅 | base(박스매입) | 실제 매입가 | 필요 N |
|---|---|---|---|
| **1세트** | 박스매입단가 | 매입단가 | **1 ÷ 박스내품** (등록 필수) |
| {박스내품}세트 | 박스매입단가 | 박스매입단가 | 1 (기본값, 등록 불필요) |

★ **N값이 `unit_list` 입력값(1/박스내품)과 정확히 같다** — 그 컬럼의 용도가 이것.
★ **미등록 시 1세트 리스팅 마진이 −166~−327%로 뜬다**(2026-08-13 4종 8건 실측:
J호 −166.1% · I호 −226.6% · L-3호 −327.3% · L-2호 −167.7%). 채널마진모니터·두뇌④ 전건 오탐.
★ 키 = **마스터상품번호**(ESM 등록결과 export의 첫 컬럼), 채널 문자열 = 소문자 `esm`.
  (기존 esm hapo 394건이 전부 마스터상품번호로 매칭 — 사이트상품번호 매칭 0건)
★ 동일 패턴 선례: 칸타타 N=0.2(박스내품50 중 10개 판매) · 리치스 N=0.833(6 중 5개).

### (5-B) ESM 배송/구매수량 설정 — 실측 검증 완료 (2026-08-13)

## 11. 함정

- **선물세트는 두뇌④ 시즌 제외(⑧) 대상** → 채널마진모니터/두뇌④ 작업목록에 안 뜬다. 이 트랙이 그 대체.
- **명절 YoY 배수를 그대로 외삽하지 말 것.** 추석 오픈마켓 YoY: 2.75배(23→24) → 4.30배(24→25).
  설 YoY는 1.48배 → 2.08배. 가속 중이나 4.3배 재현 가정은 위험.
- **설 실적으로 추석을 예측하지 말 것.** 추석/설 배율이 1.28배(추석24/설25) → 2.64배(추석25/설26)로 벌어지는 중.
  설26 4.66억이 낮은 건 라인업이 죽어서가 아니라 **설이 구조적으로 작은 명절**이기 때문
  (판매코드 34개 동일, 조합당 매출만 910만→409만).
- **규모↔마진 역상관 실증**: 추석25에 규모 4.3배 키우면서 ESM 11.5→7.3 · 스스 10.7→7.1 · 쿠팡 9.8→7.3이
  **동시에** 빠졌다. 볼륨을 가격으로 산 것. 성장률을 낮추면 마진은 회복된다(설26 9.8%).
- **"이익률 몇 %"를 단독 KPI로 걸면 보수안을 고르게 되는 함정.** 매출을 키울수록 이익률은 떨어지나
  이익 절대액은 커진다(12.35억 9.5% 1.17억 / 15억 8.8% 1.32억 / 25.6억 7.0% 1.79억).
  → 이익 **절대액**을 목표로, 마진율은 하한으로.
