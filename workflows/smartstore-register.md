# smartstore-register (스마트스토어 상품 등록) — 플랫폼 인스턴스

> 공통 개념(낱개/박스 · 합포장→배송비N · 마진 산정공식 · 상품명 정제 · 카테고리 매핑 · 캐시 · 서식 일치)은
> **workflows/product-registration-common.md** 참조. 이 문서는 **스마트스토어 전용 값**만.

## 표준 입력시트 (사용자 제공 — 2026-06-12 확정)
일상 운영은 **10열 입력시트** 1장으로 받는다(이미지URL 사전기입형, 멀티채널 v2폼 아님). 컬럼:
`상품코드 · 관리코드 · 상품명(raw) · 박스/낱개 · 최대합포(박스기준) · 목표마진율 · 면세/과세 · 카테고리(빈칸=AI채움) · 대표이미지URL · 상세이미지URL`.
- 매입가·박스내품은 시트에 없음 → **product_master.csv 관리코드 조인**(낱개=매입단가/박스=박스매입단가, 박스내품).
- 처리 순서: master 조인 → 판매가/N/배송코드/A코드 산정 → 카테고리 AI매칭(애매=사용자 상의) → 상품명 AI정제(다브랜드/내부표기 정리, 사용자 확정) → 양식 작성·서식검증 → outputs 저장. (logs/2026-06-12-smartstore-batch-12)

## 스마트스토어 전용 값
- **수수료율**: 6%.
- **배송 경제**: 공통(고객 3000 / 실비 2500).

## 양식(일괄등록) — 채우는 13개 컬럼 + 셀 타입/서식
> 양식 93열·헤더 2행(1=섹션, 2=필드명)·예시 2행(3·4, 삭제 후 3행부터 작성). 아래 13개만 채우고 나머지 빈칸 유지. 셀 타입/서식 100% 일치.

| 컬럼 | 항목 | 값 | 타입/서식 |
|---|---|---|---|
| A | 판매자상품코드 | 낱개=PC+상품코드6 / 박스=관리코드 | str / General |
| B | 카테고리코드 | 매핑 | **str**(숫자처럼 보여도) / General |
| C | 상품명 | 정제 | str / General |
| D | 상품상태 | 신상품(고정) | str |
| E | 판매가 | 공식 | **int** |
| F | 단위가격 사용여부 | N(고정) | str |
| J | 부가세 | **'과세상품' / '면세상품'**(실물값) | str |
| L | 재고수량 | 9999(고정) | int |
| W | 대표이미지 | URL | str |
| Y | 상세설명 | `<img src='...' />` | str |
| AD | 원산지코드 | 03(고정) | str + 서식 `@`(앞자리0 보존) |
| AI | 배송비템플릿코드 | N별 매핑 | **int** |
| BD | A/S템플릿코드 | 3379093(고정) | int |

> ⚠️ 위 13개는 **일반 상품 기준**이다. **선물세트는 BY(판매자바코드)=N 이 추가로 필수** — 아래 선물세트 절 참조.
> 예외 규칙이 있는 품목군은 이 표만 보지 말고 **전용 절의 컬럼까지 합쳐서** 볼 것.

## ★ 선물세트 전용 규칙 (2026-08-13 확립)

- **1세트 단위로만 등록**(사용자 확정 2026-08-13). 박스 리스팅 중복 등록 안 함.
  ※ 스마트스토어는 **판매자상품코드 중복 허용**(기존 51-30-03 4건·50-71-02 4건 동일코드) — 필요해지면 박스 추가 가능.
- **A 판매자상품코드 = 관리코드**(PC코드 없음. 선물세트 자기참조 — giftset-season-ops §8-B).
- **E 판매가 = 1세트 `매입단가` 기준**(박스매입단가 아님).
- **AI 배송비템플릿 N = 박스내품**. 선물세트는 `product_attributes` 합포수량이 전건 1이라 곱할 게 없고,
  1세트 리스팅의 묶음 단위가 곧 1박스 분량(ESM 실측으로 확인 — 3/4/5개당 3,000원).
  → N=3 `2561477` · N=4 `2756600` · N=5 `2761144`.
- **B 카테고리 = `50012020`(식품>통조림/캔>세트)**. ★ 스마트스토어 카테고리표에 **식용유 선물세트 분류가 없다**
  (`식용유/오일` 하위는 카놀라유·올리브유 등 단품뿐) → 오일 위주 세트(I호)도 통조림/캔>세트로 통일.
  ESM은 유지류세트(`00030002002600050000`)가 따로 있어 채널 간 카테고리가 달라진다.
- **상품명 = `{브랜드} {호수} 1세트 명절 추석 선물세트`**. 기존 등재 관행(`동원참치 T18호 1세트 명절 추석 선물세트`).
  ESM 등재명(`… 1세트`)과 의도적으로 다름 — 스마트스토어는 검색 키워드가 상품명에 물리므로 채널별 최적화.
- 유료/무료배송 병행 관행 있음(무료 = 판매가 +3,000, 배송비 0). 이번 배치는 **유료 단일**.
- ★★ **BY(77) 판매자바코드 = N(1÷박스내품)**. **등록 양식에서 반드시 채울 것.**
  스마트스토어는 `CHANNEL_CONFIG`에 `n_source:"ref"`가 없는 유일한 채널이라 `hapo_multiplier.csv`가 아니라
  **이 칸이 N의 정본**이다(cmm이 `_num(rec["바코드"])`로 폴백). 누락 시 N=1 → 매입가에 박스매입단가가 통째로
  잡혀 **마진 −170~−363%**.
  ⚠️ **등록 후에는 일괄수정으로 채우기 어렵다** — 일괄수정 양식은 "필수가 아닌 항목을 공란으로 올리면 삭제"가
  규칙이라, 상품번호+바코드만 채우면 판매자상품코드·대표이미지·상세설명·원산지·A/S템플릿이 함께 지워진다.
  전체 export를 받아 되올리거나 상품 편집 화면에서 수기 입력해야 하므로 **등록 시점에 넣는 것이 유일한 저비용 경로**.
  (2026-08-24 실사고: 45-28·45-20-05 등록 시 BY 누락 → 공란 등록 → 수기 보정)
- **B 카테고리 = 생활용품 선물세트는 `50001780`**(2026-08-24 사용자 제공). 식품 세트는 `50012020`.
  `reference/smartstore_category_food.csv`는 식품 631종뿐이라 비식품은 룩업 불가 — 카테고리찾기 팝업 값을 받아 쓴다.
- ⚠️ **기존 선물세트 등재가는 8~9%대**(예 50-71-02 매입 18,500 → 판매 23,000, 5% 공식이면 20,500).
  신규 4종은 **5%로 진행**(사용자 확정) → 시즌 목표(스마트스토어 9.0%) 상향은 D-25(8/31) 전 별도 결정.
