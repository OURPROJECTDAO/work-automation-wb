# 0032. ESM 부진 대응 — 기준마진 인하 이전에 '정렬'이 먼저

- 날짜: 2026-08-28 (D-28)
- 상태: 1단계 실행 완료 / 2단계 보류
- 관련: workflows/giftset-season-ops.md §2 · channel-margin-monitor.md

## 배경

D-28 진도판에서 ESM만 작년의 20%(985만 vs 4,844만). 나머지 채널은 전부 작년 이상/동등.

8/12 가설 "ESM 제약 = 품목 수"는 **오답**으로 확인. 실측 = 39/40 등재 · 깊이 평균 5.0 ·
1건뿐인 코드 0종 · 역마진 0. 팔 물건도 마진도 정상.

진짜 원인 = **가격**. 세트당 실판매가 비교에서 **39종 전부 ESM이 최고가, 평균 +12.4%**.
뿌리는 **수수료 구조**: `(1−0.06)/(1−0.175) = 1.139` → 같은 마진이면 스스 대비 구조적 +13.9%.
선물세트는 규격품이라 채널 간 비교가 그대로 일어난다.

## 결정 = ① 먼저, 단독으로 (사용자)

사용자 지적 "기준마진율에 안 맞는 애들이 문제네?"가 정확했다.
라인업 195건 중 **110건이 기준 초과**(가격이 기준마진 위로 떠 있음). 초과분 평균 −2.87%.

★ **핵심 논리: 정렬은 인하가 아니다.** 기준마진율은 이미 확정된 값이고, 가격이 그 위로 떠 있던 것은
관리 누락이다(45-27은 리스팅 6건 전부 초과, 여유 4.5%p). 권장가로 맞추는 것은 **원래 의도한 마진으로
되돌리는 것**이라 인하 재원 2,200만과 무관하다.

**공짜 수단을 먼저 쓰고 반응을 본다.** ①과 ②를 동시에 집행하면 재원을 쓰고도 효과 귀속이 안 된다.

## 실행 결과 (당일)

사용자가 195건 전건 적용 → **초과 0 · 미달 0 · 3%미만 0 · 평균마진 4.61% · 최저 3.00%**
격차 **+12.4% → +11.1%**(중앙 +9.8%), 10%↑ 32종 → 19종. **5% 이하는 여전히 0종.**

## 보류 (②) — 집행 시 우선순위

여유(현마진−기준마진)가 큰 것부터. **1군 7종 = 589만**:
45-07-03 · 45-21 · 51-30-01 · 45-18-02 · 45-27 · 50-20-01 · 50-21-01.

★ **인하 불가**: 45-11(여유 1.1%p) · 50-75-02(3.1%, 하한) · 45-07(3.9%, 기준 미달)
— **작년 ESM 매출의 45%인데 여력이 없다.** 이 셋은 가격 아닌 수단(광고·쿠폰)이 필요.

## 한계 (기록해둘 것)

**가격만으로는 격차를 5% 안쪽에 못 넣는다.** 수수료 17.5%가 구조적 하한을 만든다.
전 품목 3% 하한까지 밀어도 8.4%가 바닥. → ESM 6.0억(지마켓 단독 +57%)은
**가격·품목 수 어느 쪽으로도 달성 경로가 없다**는 것이 D-28 시점 판단.
④(목표 하향·재배분)가 유력하며 **9/10 D-15 트리거**에서 결정.

## 재원 회계 주의

정렬(①)은 재원 소모 0으로 계상한다. 다만 정렬로 **실현 마진이 8~9%대에서 4.6%로 내려간** 것은 사실이므로,
포트폴리오 이익 추정에는 반영해야 한다(기준마진대로 벌던 게 아니라 그 이상 벌고 있었던 것).
